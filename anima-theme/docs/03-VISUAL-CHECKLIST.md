# Visual comparison checklist

Used by the review agents. Items marked **(ref)** must be re-checked against the Sarah O. reference site and the owner's screenshots once they are available. Neither could be accessed during this build.

## Global
- [ ] Announcement bar is slim (≤ 40 px), with one message visible at a time and rotation that can be paused (hover or focus).
- [ ] Header has enough breathing room: logo is crisp, nav fits on one line at 1280 px, and icons are 44 px tap targets.
- [ ] Typography pairs an editorial serif for headings with a clean sans for body; small caps are used for labels.
- [ ] Only one accent color is used, with no gradients and no drop shadows on cards.
- [ ] Section spacing is consistent (80–96 px desktop) and no section looks cramped.
- [ ] Nothing scrolls sideways at 390, 768, 1024 or 1440 px.

## Homepage
- [ ] The hero image is full-bleed and the headline is legible over the image, with an overlay control.
- [ ] Trust strip: a single hairline-framed row with thin separators and no icons by default.
- [ ] Category cards: large portrait images, title below, and a subtle zoom on hover. **(ref)**
- [ ] New arrivals: the carousel aligns with the page grid, prices are visible and badges are restrained.
- [ ] Brand story: generous image, serif heading and short paragraph, with an image-left/right option.
- [ ] **Inspiration Station** **(ref: owner screenshot)**
  - [ ] Horizontal row of vertical cards with varied heights.
  - [ ] A visually prominent centre card.
  - [ ] Clean white background, minimal spacing (≈ 16–24 px) and rounded image corners.
  - [ ] A product card under each image: thumbnail, name and live price.
  - [ ] Optional creator name or @handle on the image, never cluttered.
  - [ ] Swipeable on mobile, opening centred on the featured card.
  - [ ] Feels editorial, not like an Instagram grid.
- [ ] The editorial spotlight is split 50/50, with the soft background on the text side.
- [ ] Reviews show only real ones; the section is hidden when there are none.
- [ ] Social gallery is an even square grid with a hover caption.
- [ ] The newsletter is minimal: underline field with a text button.
- [ ] Footer: brand column, link columns, contact, newsletter, payment icons and legal links.

## Product page
- [ ] The gallery dominates: editorial grid on desktop, swipe with dots on mobile, and zoom.
- [ ] Info column order: title → price → stock → options → quantity → Add to bag → benefits → details.
- [ ] Metal swatches plus size buttons, with the size guide link next to the size option.
- [ ] Add to bag is visible without scrolling on mobile.

## Collection page
- [ ] Banner with title and description (image optional).
- [ ] Toolbar with filter, product count and sort in a single row.
- [ ] Even 4-column grid on desktop and 2-column on mobile.
