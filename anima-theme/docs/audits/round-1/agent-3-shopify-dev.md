# Agent 3 — Shopify Development Audit (Round 1)

Theme: `anima-theme` (Anima Editorial, OS 2.0). Read-only review of layout, all sections and snippets, templates, section groups, `assets/theme.js`, settings and locales.

## Verdict

**Not ready to ship. Several fixes are needed before launch.** The schemas are clean: the custom linter finds nothing, and font, richtext and url defaults are valid. The Liquid object usage is mostly correct: `shop.metaobjects.inspiration_post.values`, `video.sources`, `routes.product_recommendations_url`, the predictive search `resources[...]` params, and `section_id` against a static section file all work.

These need fixing first:
1. **Theme Check does not report 0 problems.** Today it reports `ERROR LiquidHTMLSyntaxError snippets/product-card.liquid:37`. This is a real `<div>` imbalance, and it breaks every product card (D3-01).
2. **Reflected XSS.** Raw `search.terms` is printed inside `<title>` (D3-02).
3. **Buy it now can buy the wrong variant**, or a sold-out one (D3-03).
4. **The cart page can fail to re-render after a change.** The cart page section is requested from `/` instead of `/cart` (D3-04).
5. **Theme Editor re-initialisation is incomplete**, and it stacks duplicate listeners (D3-09).

## Not issues (checked, OK on real Shopify)
- `shop.metaobjects.inspiration_post.values` and `post.<field>.value` access pattern are correct. `video.sources` with `format`/`height`/`url` is valid.
- `/search/suggest?…&resources[type]=product,query&resources[limit]=4&section_id=predictive-search` is valid. A static section file name works with `section_id`.
- `/products/<handle>?section_id=product-card-render` (recently viewed) and `?section_id={{ section.id }}` on the same collection URL are valid Section Rendering API calls.
- `/cart/add.js` with FormData plus `sections`/`sections_url`: `cart-drawer` is a static section, so its id is literally `cart-drawer`. Correct.
- The `form 'product'` hyphenated attrs, `image_tag` params (`widths`, `sizes`, `fetchpriority`, `style`), `paginate … by` ≤ 48, `section.index`, `request.design_mode` and font defaults (`playfair_display_n4`, `assistant_n4`) are all valid.
- Facet param names come from `filter.*.param_name` / `value.param_name`, and `sort_by` / `url_to_remove` are used correctly.

## Top 5 must-fix
1. **D3-01**: close `.product-card__media-wrap` in `snippets/product-card.liquid`. Theme Check reports it as an ERROR, and the quick-add button covers the title and price on every card.
2. **D3-02**: escape `search.terms` in `layout/theme.liquid:20` (reflected XSS).
3. **D3-03**: hide or disable the dynamic checkout button and clear the variant id for unavailable or non-existent combinations. Today Buy it now can purchase the wrong variant.
4. **D3-04 + D3-05**: re-render the cart page from the cart URL (or bundle `sections` into `change.js`), and change lines by `item.key`, not by index.
5. **D3-09**: fix Theme Editor re-initialisation (scoped and guarded inits, plus collection, recommendations and search on `section:load`, and unload cleanup). Then D3-10 (render `@app` blocks in Social community).
