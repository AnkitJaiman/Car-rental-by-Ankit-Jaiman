# Agent 6: Extreme QA audit, round 1 (Anima Editorial)

**Verdict: NOT READY TO SHIP.** The purchase path works end to end in the mock. That covers card, quick add, variant, add to bag, drawer, checkout button, PDP add with quantity, and cart page qty. There are zero console errors and zero failed requests across 18 routes × 4 widths.

The **site header is broken in four ways**, though, and the other reviewers are likely to miss them because the header *looks* fine at 1440 in a static screenshot:

1. The desktop "Rings" dropdown is invisible and cannot be clicked. `/collections/rings` cannot be reached from the desktop nav.
2. The "sticky" header does not stick on any viewport.
3. One CSS class-name collision adds a blank band under the header and shortens its border.
4. Between 990 and 1279px, nav items get clipped off both ends.

On top of that, the homepage scrolls sideways at 990–1250px, and the PDP buy box is never sticky. There is also a cluster of focus-management bugs: after the cart drawer re-renders, after quick add, and after a filter change, focus falls back to `<body>`.

## Top 5 must-fix

1. **Q6-01 + Q6-04: the desktop nav.** Remove `overflow:hidden` from `.header__nav` (`base.css:216`) so the Rings dropdown renders and can be clicked, and add a "View all" link to it. Handle 990–1279px with a hamburger fallback or tighter spacing so Home, Catalog, Contact and About Us are reachable.
2. **Q6-03 → Q6-02: rename the header section class.** Change `sections/header.liquid:219` from `"section-header"` to e.g. `"section-site-header"`. That removes the 40px band and the short border. Then make that wrapper `position:sticky; top:0` so the header actually sticks.
3. **Q6-05: homepage horizontal overflow at 990–1250px.** In `.spotlight`, use `repeat(2, minmax(0,1fr))` and set the image to `width:100%`.
4. **Q6-06: PDP buy box never sticky.** Remove `align-items:start` from `.product` (`base.css:501`) so `.product__info-sticky` can engage.
5. **Q6-08 / Q6-09 / Q6-10 / Q6-13: focus management.** Restore focus after the drawer and facets re-render, use the right return target after quick add, and fix the lightbox focus trap (the `offsetParent` check in `theme.js:50` fails for fixed-position controls).
